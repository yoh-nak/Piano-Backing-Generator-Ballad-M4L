# Piano Backing Generator BALLAD for Ableton Live

**Piano Backing Generator BALLAD v2.0** is a Max for Live MIDI generator designed for creating expressive, natural-sounding piano accompaniment across a wide range of ballad styles.

It is a dedicated BALLAD edition of Piano Backing Generator, rebuilt on the improved v2.0 engine with a completely redesigned library of **2,600 presets across 26 ballad genres**.

The device transforms MIDI chord input into piano accompaniment patterns, including sustained chords, flowing arpeggios, broken chords, gentle rhythmic accompaniment, expressive two-hand performances, and powerful ballad arrangements.

It is designed for use with your preferred piano VST, Kontakt instrument, Ableton Live instrument, or other MIDI-compatible sound source.

## Independent Performance Layers

The device separates piano accompaniment into three performance layers.

**BASS**

Controls low-register accompaniment and bass movement.

**LEFT HAND**

Generates lower-register chord accompaniment, rhythmic movement, and arpeggio patterns.

**RIGHT HAND**

Generates upper-register chord textures, melodic accompaniment figures, and expressive piano patterns.

These layers allow a wide range of arrangements, from minimal piano accompaniment to fuller two-hand performances.

## MIDI Input Modes

**PERFORMANCE**

Generate accompaniment using incoming MIDI performance data.

**AUTO**

Generate accompaniment patterns using the device's automatic performance settings.

The device can work with MIDI keyboard input and existing MIDI material in Ableton Live.

## MIDI Recording and Export

Piano Backing Generator BALLAD supports MIDI recording, clip writing, and MIDI file export.

Available workflows include:

- Recording generated MIDI performances
- Writing generated notes to Ableton Live MIDI clips
- Creating new takes
- Appending performances to existing takes
- Exporting generated MIDI data to a MIDI file

### Important: CC, Pitch Bend, and Aftertouch

**Use MIDI EXPORT when you need to preserve MIDI CC, Pitch Bend, or Aftertouch data.**

Due to limitations in the supported Ableton Live clip-writing workflow, these expressive MIDI events may not be included when writing MIDI notes directly into a Live clip.

This includes sustain pedal information (CC64).

To preserve the complete MIDI performance:

1. Generate or record your accompaniment.
2. Use the device's MIDI EXPORT function.
3. Import the exported MIDI file into Ableton Live.
4. Check the MIDI notes and expression data in the imported clip.

Direct clip writing remains useful for MIDI note generation, while MIDI Export is the recommended workflow for preserving expressive MIDI information.

## Basic Usage

1. Load Piano Backing Generator BALLAD onto a MIDI track in Ableton Live.
2. Place your preferred piano instrument after the device.
3. Select a ballad genre and preset.
4. Choose PERFORMANCE or AUTO mode.
5. Adjust the BASS, LEFT HAND, and RIGHT HAND settings.
6. Play MIDI chords or use existing MIDI material.
7. Adjust the accompaniment parameters to match your arrangement.
8. Record, write, or export the generated MIDI performance.

## Chord Voicing

The device focuses on generating piano accompaniment patterns from MIDI chord input.

For more control over the harmonic structure and voicing of your chords, you can prepare your MIDI input using a separate chord-writing or voicing tool, such as **Chord Voicing Writer**.

This allows you to combine dedicated chord voicing with the accompaniment generation features of Piano Backing Generator BALLAD.

## Installation

1. Download `Piano_Backing_Generator_Ballad_v2.0.amxd`.
2. Open Ableton Live.
3. Drag the `.amxd` file onto a MIDI track.
4. Insert a piano instrument after the device.
5. Select a preset and start generating piano accompaniment.

No separate installation of external Max patches is required.
